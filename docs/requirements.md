# Requirements

Inertia Notifications requires the following versions of its dependencies:

| Dependency | Version |
| --- | --- |
| PHP | 8.3+ |
| Laravel | 12 or 13 |
| Inertia Laravel | 3.8+ |
| Inertia.js | 3.11+ |
| Vue | 3.5+ |
| React | 19 |
| Tailwind CSS | 4.3+ |

On the frontend, you need either Vue or React, not both.
